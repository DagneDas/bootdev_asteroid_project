To play the game:
1. Create a virtual environment with 'uv init --no-package --python 3.13 your-project-name'.
2. Navigate to the project folder and type 'uv venv'.
3. Activate the environment with 'source .venv/bin/activate'.
4. Add the pygame library as a project dependency with 'uv add pygame==2.6.1'.
5. Run the game with 'uv run main.py'.
6. Deactivate the environment with 'deactivate'.
